# discord-numeragon-ai-bot
ぬめらごんの分身を作ろうプロジェクト

サーバーの会話の雰囲気（口調・スラング・絵文字・よく出る話題）を学習し、
人の会話に自然なタイミングで混ざるBot。

## 仕組み
- チャンネルの発言をサーバーごとに直近2,000件まで保存（data/<guild_id>/messages.jsonl）
- 150件たまるごとにLLMが「雰囲気プロファイル」を要約・更新（profile.json）
- 返信時は 直近25件の会話 + 雰囲気プロファイル をLLMへ渡して生成
- 会話参加ルール: メンション/返信は即応答。通常時は「2人以上の会話が3件以上続いた後、
  20〜55秒の間が空いた時」に確率35%で参加、チャンネルごとに最低4分のクールダウン
- 人間らしく typing 表示を入れてから送信

## 頭脳の切り替え（config.json の llm_backend）
- `openai`: OpenAI互換APIを直接使用（.env の OPENAI_API_KEY）。高速・利用枠ゼロ
- `relay`: data/relay/inbox にリクエストを置き、外部エージェント（Muse）が
  outbox に回答を返す方式。APIキー不要だが応答は遅め

## 起動
1. Discord開発者ポータルでアプリ作成 → Botトークン発行 →
   Privileged Gateway Intents の **MESSAGE CONTENT INTENT** をON
2. OAuth2 URL Generator で bot スコープ（権限: メッセージ送信/閲覧/履歴閲覧）を発行しサーバーへ招待
3. `.env` に DISCORD_TOKEN（方式がopenaiなら OPENAI_API_KEY も）を記入
4. 常駐: systemd ユーザーサービス `discord-vibe-bot.service` を有効化

## 画像認識
- メンバーが貼った画像（添付・GIFピッカー・返信先の画像）は、Geminiの画像認識で内容を説明するテキストに変換して会話履歴に取り込むため、Botが画像の内容を見て反応できる
- 画像だけの投稿でも会話の流れとして扱われ、通常の会話参加・話しかけ判定・DMのすべてで画像の内容に触れた返信になる
- GIF等の動画系画像は先頭フレームを静止画化して認識する。同一チャンネルで短時間に連続した画像は一部スキップされることがある

## 動画・音声の取得
- 会話に YouTube / X（Twitter）のURLを貼って「この動画持ってこれる？」「音声だけ落として」のように頼むと、Botがファイルを取得してそのチャンネルに添付する（URLだけ先に貼って、後から頼んでも直近15分以内のURLを拾う。返信で指定も可）
- 「音声」と言われたら mp3、それ以外は mp4 動画。Discordの添付上限（25MB）に収まるよう画質を 720p→480p→360p と落として試す
- 依存: yt-dlp と ffmpeg。長さ1時間超え・ログイン必須・非公開のものは取得できない旨を返す

## カジノ（仮想コイン）
- 「カジノしたい」と言うか `/カジノ` コマンドで、ボタン式の専用パネルが開く（DMでも可）。パネルは開いた本人のボタンだけ反応する
- 通貨は「2009コイン」：無料配布のみのBot内専用ポイントで、購入・換金・譲渡・現実の商品との交換はできない。初回1,000、デイリー（毎日+500）と発言（1分ごと+2）で貯まる。残高はサーバーごとに `data/<guild_id>/casino.json` へ保存
- ゲーム：スロット（3つ揃い最大20倍、ペア1.5倍）、コイントス（1.9倍）、ダイス勝負（勝ち1.9倍・引き分け返金）、ブラックジャック（勝ち2倍、BJ2.5倍）。賭け金は10/100/500/1,000をボタンで切替
- ショップ：貯めたコインをBot内のバッジ・称号（コレクション要素）と交換できる。ランキング表示あり
- Web連携：config.json の `casino_web_url` にWebカジノ（静的サイト）のURLを設定すると、「カジノしたい」でパネルの代わりにセッションリンクを送る。残高全額を2時間のセッションにロックして持ち込み、サイトが発行する精算コード（`NCSETTLE:...`）をチャットに貼ると、Botが署名と計算式（最終残高＝持ち込み−累計ベット＋累計獲得−ショップ代金）を検証して精算する。期限切れは次回操作時に自動返金。URL未設定なら従来のパネルが開く。ショップ商品はサイト側の設定で変更可能で、精算コードには商品のID・名前・価格が含まれ、Botはその価格で計算を検証して名前ごと付与する（旧形式のIDのみのコードも互換で受け付ける）

## オーナーコマンド（config.json の owner_id を設定した場合）
- `!botpause` / `!botresume` : そのチャンネルでの自動参加を停止/再開
- `!botprofile` : 雰囲気プロファイルを即時更新して表示
